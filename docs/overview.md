# Garage Tech Lab — 12 weeks

**Audience:** curious builder with software experience who wants hands-on competence in vehicle electronics and embedded computing.

**Schedule:** 3–5 hours per week; progress at your own pace. Each module combines theory, safe workbench practice, and an application to both vehicles or the Raspberry Pi.

| Week | Module | Hands-on objective |
|---|---|---|
| 1 | [Electrical fundamentals](./01-electrical-fundamentals.md) | Measure battery voltage; build a low-power bench LED circuit |
| 2 | [Multimeter skills](./02-multimeter.md) | Measure voltage, resistance, and continuity safely |
| 3 | [Grounds and faults](./03-grounds.md) | Diagnose a simulated high-resistance return path |
| 4 | [Wire, taps, and fuses](./04-wiring.md) | Design and crimp a fused demo harness |
| 5 | [Relays and lighting](./05-relays.md) | Prototype isolated relay-driven courtesy lighting |
| 6 | [DC-DC and USB](./06-power.md) | Measure buck converter input/output power |
| 7 | [Charging systems](./07-charging.md) | Compare alternator and stator/regulator architectures |
| 8 | [Vehicle networks](./08-networks.md) | Read OBD-II data safely and passively |
| 9 | [Raspberry Pi GPIO](./09-raspberry-pi.md) | Read sensors using protected interfaces |
| 10 | [GPS telemetry](./10-gps.md) | Parse GPS sentences and log routes locally |
| 11 | [Camera and edge AI](./11-camera.md) | Combine timestamps, camera images and sensor events |
| 12 | [Garage Intelligence capstone](./12-capstone.md) | Build a vehicle telemetry dashboard |

## Your training platforms

- **2014 Ford F-150 SuperCrew** — electronically controlled lighting, accessory integration, OBD-II and modern wiring.
- **1997 Harley-Davidson 883 Hugger** — traditional circuits, switches, relay logic, stator and charging regulator.
- **Raspberry Pi + GPS + camera** — embedded Linux, serial protocols, physical sensors, local telemetry and vision.

:::warning Measure before modifying
Exact pinouts, wire colors, circuit capacity and component ratings **must be verified** using applicable service documentation. This course does not certify a circuit safe to install.
:::

## How to use each week

1. Read the lesson and work the examples.
2. Reproduce the circuit on a current-limited bench setup.
3. Complete the garage observation or measurement task.
4. Record findings locally, not in this public repository.
5. Answer the knowledge check before moving on.

Try the [electrical toolbox](/tools) or explore the [vehicle labs](./labs/overview.md).
