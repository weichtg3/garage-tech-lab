# Learning by building

The course uses **three platforms**: a 2014 Ford F-150, a 1997 Harley-Davidson Sportster 883 Hugger, and an existing Raspberry Pi with GPS and camera.

Start with low-energy bench circuits and only then advance to observational measurements on your vehicles.

- [F-150 experiments](./f150.md)
- [Sportster experiments](./sportster.md)
- [Raspberry Pi experiments](./raspberry-pi.md)

**Personal lab data** should remain outside this public GitHub repository.
